# Towards_the_safe_operation_of_Autonmous_Vehicles_in_Work_Zones
This repository contains the links to the video demonstrations of our CMU AV that illustrate the feasibility of safe and reliable navigation of AVs in a wide variety of work zones. 
This is part of the paper "Towards the Safe Operation of Autonomous Vehicles in Work Zones" accepted in IEEE Intelligent Vehicles Symposium (IV) 2025. 

A. Evaluations in Simulation using **_CoSim_** : https://drive.google.com/drive/folders/1jPNfD4WDVYhgasz1-ZYBc2ZtTZ0p4L94?usp=drive_link
B. Evaluation On A Closed Test-Track with CADRE on CMU AV: https://drive.google.com/drive/folders/1EQScP6pn7QtWC8_yfROtmPn80nePDtjO?usp=drive_link
C. Evaluation On Real-World Public Roadway Work Zones with CADRE on CMU AV: https://drive.google.com/drive/folders/1MotCTRz5Zf6E8V09_ka2X-E7b2oqY8oI?usp=drive_link
